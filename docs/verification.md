- Public Git history was rewritten and force-pushed at the owner’s explicit request, preserving the work-package commit structure while replacing prior ID/telegram references. Older releases/tags, four original CI runs and their artifacts/logs, and 47 affected build caches were deleted. All reachable local Git objects, including application snapshot refs, were checked for prior identity/capture references.
- The owner manually deleted the legacy GHCR versions after the API refused deletion under its public-download limit. Public version listings and anonymous registry requests confirmed the old versions/tags and original release digest are unavailable. After the force push, GitHub initially still served an old Git commit by its previous SHA. The owner then deleted and recreated the repository; the cleaned local main branch and v0.2.0 tag were pushed, and that former SHA now returns "No commit found" through GitHub's API. This verifies current access, not permanent erasure of GitHub's retained backups. No container image or executable bytes were patched: text was edited, the public fixture was generated anew, and new images were built from source.

## Direct Proxmox LXC installer

An interactive host installer targets Proxmox VE 9.1+ OCI application containers on amd64, importing the existing released image directly into an unprivileged LXC. It configures a single mapped SDR, protected guest secret files and private runtime tmpfs, with a host timer for startup/health/USB remapping. All 18 automated host tests passed locally and in [CI for the installer](https://github.com/andrekuehne/diehl2mqtt/actions/runs/38252328412), covering installation guards, permissions, identity matching, reconnect/restart transitions and environment handling. The same CI passed the 23 application tests, synthetic decode, conversion of the tested production image into an OCI archive while preserving startup metadata, and GHCR publication. Local deployment packaging included the standalone installer and passed all archive checksums. Actual Proxmox installation, live reception, node reboot and unplug/replug acceptance are still pending on the destination node; upstream application-container support is a technology preview.
